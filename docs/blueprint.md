# **App Name**: Campus Compass

## Core Features:

- Item Posting: Allow users to post descriptions and images of lost items.
- Item Search: Enable users to browse and search for found items with filtering options.
- User Connection: Provide a contact form or messaging system for users to connect about found items.

## Style Guidelines:

- Primary color: calming blue (#3498db) to inspire trust and security.
- Secondary color: Light gray (#ecf0f1) for backgrounds and subtle accents.
- Accent: Use a bright orange (#e67e22) for highlighting interactive elements.
- Clean and readable sans-serif fonts for clarity.
- Simple, recognizable icons for item categories and actions.
- Clean, card-based layout for displaying item information.
